Motivação e objetivos

  • O crescimento do uso de inteligências artificiais generativas;
  • A necessidade de identificar textos acadêmicos gerados por IA;
  • Desenvolver e avaliar métodos para detectar introduções de TCCs geradas por IA em português;
  • Comparar o desempenho de doc2vec combinado com XGBoost e do BERT.

Construção da base de dados

  1. Foram coletadas monografias publicadas antes de 2023 de diferentes cursos da Universidade Federal Fluminense.
  2. As introduções foram extraídas dos arquivos PDF.
  3. Um modelo de linguagem (Llama 3.1 8B), acessado pela API da Groq, foi utilizado para gerar introduções artificiais a partir dos títulos e textos originais.
  4. A base foi dividida em conjuntos de treino e teste.

  • Usa uma RNA (Rede Neural Artificial) para gerar uma representação para os termos (word2vec);

  • Leva em consideração a sequencia dos termos nos nos documentos;

  • Usa uma outra RNA para gerar uma representação vetorial dos documentos (doc2vec);

  • Os vetores gerados são mais “densos” em comparação com os metodos anteriores;

  • A dimensão k é definida pelo numero de neuronios na unicas camadas ocultas nas RNAs

Modelos avaliados

  • doc2vec + XGBoost
  • BERT
  • O doc2vec representa cada documento por um vetor numérico denso.
  • A representação considera informações sobre as palavras e o contexto do documento.
  • O XGBoost utiliza árvores de decisão em conjunto para classificar os textos.
  • Ponto de corte utilizado para a classificação: 0,5026.
  • Modelo de linguagem pré-treinado que produz representações contextuais dos textos.
  • A representação das palavras considera o contexto em que elas aparecem.
  • O modelo foi avaliado na mesma base de teste para comparação com doc2vec + XGBoost.

Conclusões

  • Os dois modelos apresentaram alto desempenho na base de teste.

  • O BERT obteve resultados gerais superiores aos do doc2vec + XGBoost nas métricas apresentadas.

  • O BERT classificou corretamente 1.243 dos 1.257 textos de teste, enquanto o doc2vec + XGBoost classificou corretamente 1.222.

  • No doc2vec, a acurácia foi elevada nos grupos avaliados, mas o tamanho reduzido de alguns grupos limita a interpretação de seus resultados.

  • A comparação reforça o potencial de métodos de representação textual para a detecção de textos gerados por IA em português.
